Warm-up run.

List `inbox/`. If there is no batch file there, stop — there is nothing to do, and that is the
common outcome, not a failure.

If there is one, work it end to end following `AGENTS.md`: read the snapshots it names oldest
first, write each file as you finish it, write the mission briefing last, advance the cursor,
write your run receipt, and move the batch into `inbox/done/`.

If a session in the batch carries `away_secs`, this run was triggered by the captain picking up
their phone, and they are reading it now. The snapshot window has been widened to cover their
absence rather than your last turn — brief them on the whole gap, and check `covers_from` before
implying you can see all of it.

Write only what changes what the engineer knows or does next. A quiet board deserves three short
lines and no memos.
